# RetailNav

The public product name is **RetailNav** (confirmed by the owner on 2026-10-12). It replaces Mall Masters in new UI, model metadata and release documentation.

Repository: `romancanoniero/MallMasters` remains unchanged for now. Renaming the GitHub repository, bundle identifiers, deployment paths or Codemagic application requires a separate coordinated change; none is implied by the product-name change.

Current mock case: Aventura Mall, based on the three user-supplied raster floor-plan images. Floor geometry is provisional and must not be presented as measured LiDAR output or certified wayfinding data.

Current viewer correction: default to all three floors, provide free rotation, two-finger pan/pinch and explicit gesture diagnostics; distinguish HTML file preview from an executing web application. Native 3D model exports are separate from the full client application.
